# @cldmv/uuid v1.1.1 Changelog

**Release Date**: March 2026
**Release Type**: Patch
**Branch**: `master`

---

## Overview

v1.1.1 is a test and tooling release. No runtime behavior changed. It brings the test suite to full coverage, adds header tooling and a CI workflow, and aligns the README badges with the other CLDMV packages.

Commits: [`4d8fdfd`](https://github.com/CLDMV/uuid/commit/4d8fdfd), [`d098aa7`](https://github.com/CLDMV/uuid/commit/d098aa7)

---

## 🔧 CI & tooling

- **Full test coverage**: new suites for entropy sources, the issuer registry, RFC branch paths, validator branches and UUID alias / devcheck paths. The vitest default timeout is now 20 seconds.
- **Test tree renamed** from `test/` to `tests/`.
- **Coverage scripts**: `coverage`, `test:coverage` and `ci:coverage`.
- **Header tooling**: `tools/fix-headers.mjs` + `npm run fix:headers` (via `@cldmv/fix-headers`) standardize the file headers across the repo.
- **First CI workflow**: `.github/workflows/ci.yml`.

## 📚 Documentation

- The README badges use the grouped, reference-style layout shared with `@cldmv/fix-headers`.

## 🔧 Dependencies

- Added devDependencies `@cldmv/fix-headers` and `@vitest/coverage-v8`. `vitest` moved to `^4.0.18`. There are still no runtime dependencies.

---

## Upgrade notes

- No breaking changes and no runtime change.
- **Known issue:** as in v1.1.0, the published package lacks `types/index.d.mts`, so TypeScript consumers get no root declarations. [v1.1.2](./v1.1.2.md) fixes this.
