# @cldmv/uuid v1.2.1 Changelog

**Release Date**: September 2026
**Release Type**: Patch
**Branch**: `release/1.2.1`

---

## Overview

v1.2.1 is a CI and release-automation update. **No runtime code changed**, and the published package is functionally the same as v1.2.0.

---

## 🔧 CI & tooling

### Pass `BOT_NAME` / `BOT_EMAIL` to the v4 release and feature-PR workflows ([#25](https://github.com/CLDMV/uuid/pull/25), release [#27](https://github.com/CLDMV/uuid/pull/27))

The next / hotfixes release workflows and the feature-PR workflow now receive the bot identity. The generated changelog's contributor list can then tell the automation bot apart from human contributors.

### Sign redirected Dependabot security PRs ([#26](https://github.com/CLDMV/uuid/pull/26))

The hotfix-redirector caller now maps the `CLDMV_BOT_*` GPG signing secrets. The Dependabot security-redirect path cherry-picks onto `hotfixes` and has to sign that commit. Without the key, the required-signatures ruleset silently blocked the redirected PR (see [CLDMV/.github#257](https://github.com/CLDMV/.github/issues/257)).
