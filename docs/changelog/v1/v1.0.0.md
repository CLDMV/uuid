# @cldmv/uuid v1.0.0 Changelog

**Release Date**: December 2025
**Release Type**: Major (initial release)
**Branch**: `master`

---

## Overview

This is the first public release of `@cldmv/uuid`. It implements an extended UUID specification that adds a custom variant (`111`) to the RFC 4122 / RFC 9562 namespace, and it also ships a full set of standard RFC UUID generators.

---

## ✨ Features

### Extended UUID specification

- **Custom variant `111`**: entry into the extended namespace through bits 64–66, with a subvariant system for Timestamp (`00`) and Issuer (`01`) branches plus reserved expansion slots.
- **Timestamp variants**: `UUID.TA(timestamp)` and `UUID.TB(timestamp)` build on a signed 70-bit timestamp. The general form is `UUID.timestamp(timestamp, version)`, also available as `UUID.createTimestampVariant()`.
- **Issuer variant**: `UUID.IA(issuerID)` uses a 10-bit issuer ID space (0–1023) with categorized allocation ranges. The general form is `UUID.issuer(issuerID, version)`, also available as `UUID.createIssuerVariant()`. A bundled issuer registry (`src/data/issuers.json`) holds the allocations.
- **Formal specification**: [`uuid-spec.md`](https://github.com/CLDMV/uuid/blob/master/uuid-spec.md) documents the bit layout, entropy requirements and collision-resistance analysis.

### Standard RFC UUIDs

- `v1`, `v3`, `v4`, `v5`, `v6` and `v7` generators, plus `parse`, `stringify`, `validate` and `version`, the `NIL` / `MAX` constants, and the `DNS` / `URL` / `OID` / `X500` namespaces.

### Packaging

- ESM-first package with a CommonJS entry (`index.cjs`) and TypeScript declarations under `types/`.
- No runtime dependencies. Randomness comes from Node's `crypto`.
- A `uuid-dev` export condition resolves to `src/` for local development; the default resolution is `dist/`.
- Requires Node.js `>=18.12`.

## 🔧 CI & tooling

- A vitest suite covers bit utilities, collision resistance, the custom variants, validators, the RFC generators and integration paths.
