# @cldmv/uuid v1.1.3 Changelog

**Release Date**: August 2026
**Release Type**: Patch
**Branch**: `release/1.1.3`

---

## Overview

v1.1.3 moves the repository onto the CLDMV v4 staging-branch release flow and runs the tests through `@cldmv/vitest-runner`. No runtime code changed.

> **Not published to npm.** Publishing failed for v1.1.3 through v1.1.6 until npm Trusted Publishing was set up for the package, so this version exists only as a [GitHub Release](https://github.com/CLDMV/uuid/releases/tag/v1.1.3). v1.1.7 is the next version on npm, and it includes these changes.

---

## 🔧 CI & tooling

### Onboard to the CLDMV v4 flow ([#2](https://github.com/CLDMV/uuid/pull/2), release [#3](https://github.com/CLDMV/uuid/pull/3))

- Added the full v4 workflow set: CI, CodeQL, Scorecard, dependency review, CLA, feature-PR auto-open, next / hotfixes release PRs, next-reset, hotfix redirector, publish, tag health, major-version tags, branch retention, labeler, stale, welcome and release-notify. Also added `.github/dependabot.yml`.
- Tests run through `@cldmv/vitest-runner` (`tests/run-vitest.mjs`). `test`, `coverage` and `ci:coverage` all go through that runner, and `build:ci` was added for the CI pipeline.

## 🔧 Dependencies

- Added the dev-only `@cldmv/vitest-runner`. `vitest` and `@vitest/coverage-v8` moved to `^4.1.10`.

---

## Upgrade notes

- No breaking changes and no runtime change.
