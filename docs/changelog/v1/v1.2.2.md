# @cldmv/uuid v1.2.2 Changelog

**Release Date**: September 2026
**Release Type**: Patch
**Branch**: `release/1.2.2`

---

## Overview

v1.2.2 moves the test toolchain to vitest 5 and updates the CI Node matrix to match. **No runtime code changed.** The package's own `engines.node` stays at `>=16.12.0`.

---

## 🔧 CI & tooling

### Node CI matrix for vitest 5 ([#32](https://github.com/CLDMV/uuid/pull/32))

vitest 5 declares `engines.node` `^22.12.0 || ^24.0.0 || >=26.0.0`, so the CI and publish test matrices now run from Node 22.12.0 up to 26. The package's `engines.node` floor stays low on purpose, for downstream consumers. The test floor is a dev-toolchain concern only.

### Grouped Dependabot bumps

`vitest` + `@vitest/*`, the eslint family and the prettier family each bump in a single grouped PR now. These packages peer each other with major-locked ranges, so separate PRs broke `npm ci` with `ERESOLVE` whenever one moved without the others.
