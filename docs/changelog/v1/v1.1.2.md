# @cldmv/uuid v1.1.2 Changelog

**Release Date**: March 2026
**Release Type**: Patch
**Branch**: `master`

---

## Overview

v1.1.2 restores the root TypeScript declarations. v1.1.0 and v1.1.1 shipped without `types/index.d.mts` even though `package.json` `"types"` pointed at it. This release adds the file back and adds scripts to rebuild and check the declarations.

Commits: [`d48c1b0`](https://github.com/CLDMV/uuid/commit/d48c1b0), [`199d3ba`](https://github.com/CLDMV/uuid/commit/199d3ba), [`22af986`](https://github.com/CLDMV/uuid/commit/22af986), [`30b622a`](https://github.com/CLDMV/uuid/commit/30b622a), [`8053087`](https://github.com/CLDMV/uuid/commit/8053087)

---

## 🐛 Bug Fixes

### Root type declarations restored

`types/index.d.mts` (and its source map) ships again. It declares the default `UUID` export, the named `UUID` / `uuid` exports and `ISSUER_CATEGORIES`. The TypeScript declaration config in `.configs/tsconfig.dts.jsonc` was updated to match.

## 🔧 CI & tooling

- New `types:build` and `types:check` scripts.
- A dedicated CI coverage config (`.configs/vitest.ci.config.mjs`) and a `ci:coverage` script. The coverage badge figure now matches the coverage report.

---

## Upgrade notes

- No breaking changes. TypeScript consumers on v1.1.0 or v1.1.1 should upgrade to get the root declarations back.
