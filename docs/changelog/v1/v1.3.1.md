# `@cldmv/uuid` v1.3.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/1.3.1`

---

## Overview

v1.3.1 sets `engines.node` back to the Node.js version the package needs at runtime, `>=16.12.0`, instead of the 22.22.0 development toolchain floor that v1.3.0 put there. The 22.22.0 floor moves to npm's `devEngines`, which only applies when you work on this repository.

The `UUID` API, the generated UUIDs and the import paths are the same as in v1.3.0. Installs on Node.js 16.12 through 22.21 no longer get an `EBADENGINE` warning.

---

## 🐛 Bug Fixes

### `engines.node` is the runtime floor again ([#85](https://github.com/CLDMV/uuid/pull/85))

v1.3.0 raised `engines.node` from `>=16.12.0` to `>=22.22.0` because the development toolchain (tsup 9 among others) doesn't run on earlier 22.x releases. The published package doesn't need any of that toolchain, so the floor was stricter than the code. `engines.node` is `>=16.12.0` again, and the bundles are built for `node16` (tsup `target`, was `node20`).

`import` works on Node.js 16.12.0 and later. `require("@cldmv/uuid")` loads the ES module build synchronously, which needs `require(esm)`: Node.js ^20.19.0 or >=22.13.0. On a Node.js without it, the CommonJS entry now says exactly that (`require() needs Node.js ^20.19.0 or >=22.13.0`, code `ERR_REQUIRE_ESM`) and points to `import()`; v1.3.0's message asked for 22.22.0.

## 📦 Requirements

- **Runtime:** Node.js 16.12.0 or later for `import` (`engines.node` is `>=16.12.0`, was `>=22.22.0`). `require()` needs Node.js ^20.19.0 or >=22.13.0; use `import()` on older versions. Browser bundles are unaffected.
- **Development:** working on this repository needs Node.js 22.22.0 or later, declared in `devEngines.runtime` with `onFail: "error"`. This doesn't affect anyone installing the package.

## 🔧 CI & tooling

- The CI and publish workflows keep `min_node_version` at 22.22.0; its description and a comment now say it's the dev toolchain floor and should match `devEngines`, not `engines` ([#85](https://github.com/CLDMV/uuid/pull/85), [#87](https://github.com/CLDMV/uuid/pull/87)).

## Upgrade notes

- No breaking changes; drop-in for v1.3.0. Apart from the CommonJS entry's error message and the `node16` build target, no library code changed.
- If you stayed on v1.2.6 because of v1.3.0's 22.22.0 floor, v1.3.1 installs on Node.js 16.12 and later again. `@cldmv/uuid/main` is still a deprecated alias, as in v1.3.0.
