# @cldmv/uuid v1.0.2 Changelog

**Release Date**: December 2025
**Release Type**: Patch
**Branch**: `master`

---

## Overview

v1.0.2 makes a `UUID` instance behave as its string form wherever a string is expected, and lowers the minimum Node.js version.

Commit: [`6f66163`](https://github.com/CLDMV/uuid/commit/6f66163)

---

## ✨ Features

### Default string representation

- UUID instances implement `valueOf()`, `Symbol.toPrimitive`, `toJSON()` and Node's `util.inspect.custom`. Template literals, string concatenation, `JSON.stringify` and `console.log` all produce the canonical UUID string.
- `toBuffer()` gives explicit access to the binary form.
- New demo: `scripts/demo-default-string.mjs`.

## 🔧 Compatibility

- `engines.node` lowered from `>=18.12` to `>=16.12.0`, the first release line with stable top-level `await`.

## 📚 Documentation

- The README gains a "Default String Representation" section with examples.

## 🔧 CI & tooling

- Added 29 string-conversion tests, for 199 in total.

---

## Upgrade notes

- No breaking changes. Instances now convert to their string form wherever a string is expected. An explicit `toString()` call keeps working.
