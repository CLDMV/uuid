# `@cldmv/uuid` v1.2.6 Changelog

**Release Date**: October 2026
**Release Type**: Patch
**Branch**: `release/1.2.6`

---

## Overview

v1.2.6 updates the test toolchain: `vitest` 5.0.2 → 5.0.3 and `@cldmv/vitest-runner` 1.5.1 → 1.5.3. **No runtime code changed.** The net change against v1.2.5 is the version field in `package.json` and the lockfile; `index.mjs`, `index.cjs`, the type declarations and the published `files` list are identical, and the package still has no runtime dependencies. The package's own `engines.node` stays at `>=16.12.0`.

---

## 🔧 CI & tooling

### `@cldmv/vitest-runner` 1.5.3 raises its own Node.js floor ([#64](https://github.com/CLDMV/uuid/pull/64))

`@cldmv/vitest-runner` 1.5.3 declares `engines.node` `>=22.12.0` (it was `>=20.19.0` in 1.5.1), and its `chalk` dependency moves from 5.6.2 to 6.0.1, which requires Node.js 22 or newer. This only affects people who run this repository's test suite: the CI matrix already starts at Node 22.12.0 because `vitest` 5 requires `^22.12.0 || ^24.0.0 || >=26.0.0`, so CI is unaffected, and contributors need Node.js 22.12 or newer to run `npm test`. Consumers of `@cldmv/uuid` never install these packages.

### `vitest` 5.0.3 ([#61](https://github.com/CLDMV/uuid/pull/61))

`vitest` and `@vitest/coverage-v8` move from 5.0.2 to 5.0.3 together.
