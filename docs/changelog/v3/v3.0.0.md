# `@cldmv/uuid` v3.0.0 Changelog

**Release Date**: November 2026
**Release Type**: Major
**Branch**: `release/3.0.0`

---

## Overview

v3.0.0 switches the CommonJS entry to the generic `index.cjs` shim used across the CLDMV libraries. `require("@cldmv/uuid")` now returns the module object, the same exports `import` gives, instead of the `UUID` class with properties attached.

This is the only breaking change, and it only affects code that uses `require()` and treats the result as the `UUID` class. ESM `import` is unchanged, and so is every `UUID` method.

---

## 💥 Breaking Changes

### `require("@cldmv/uuid")` returns the module object ([#141](https://github.com/CLDMV/uuid/pull/141), fixes [#140](https://github.com/CLDMV/uuid/issues/140))

The ESM entry exports two distinct values, the `UUID` class (also exported as `uuid` and `default`) and `ISSUER_CATEGORIES`, so the shim hands back the module object:

```javascript
const uuid = require("@cldmv/uuid");
// => { default: UUID, UUID, uuid, ISSUER_CATEGORIES }

const { UUID } = require("@cldmv/uuid");
UUID.TB();
```

- `new (require(x))()` becomes `new (require(x).UUID)()`, or `const { UUID } = require(x)`.
- Statics called on the result, such as `require(x).v4()`, `require(x).NIL` and `require(x).DNS`, move to the class: `require(x).UUID.v4()`, `UUID.NIL`, `UUID.DNS`.
- `require(x).UUID`, `require(x).uuid` and destructuring keep working.
- `require(x).default` and `require(x).ISSUER_CATEGORIES` are newly available.

`src/index.cjs` is now the same small file as in other CLDMV libraries (Node version guard, then `require("./index.mjs")`), and the build still copies it unchanged to `dist/index.cjs`. The CJS test expects the module object and checks that the statics are no longer top-level keys.

## Upgrade notes

- `require("@cldmv/uuid")` no longer returns the `UUID` class. Use `const { UUID } = require("@cldmv/uuid")`, and call statics on `UUID` (`UUID.v4()`, `UUID.NIL`, `UUID.DNS`).
- `require(x).UUID`, `.uuid` and destructuring work as before; `.default` and `.ISSUER_CATEGORIES` are new.
- ESM `import` is unchanged.
